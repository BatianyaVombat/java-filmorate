## Структура таблиц

### Справочники

**MPA_Ratings** — возрастные рейтинги фильмов.

```sql
CREATE TABLE MPA_Ratings
(
    id   BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(10) NOT NULL UNIQUE
);
```

**Genres** — жанры кинолент.

```sql
CREATE TABLE Genres
(
    id   BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(100) NOT NULL UNIQUE
);
```

### Главные сущности

**Users** — пользователи сервиса.

```sql
CREATE TABLE Users
(
    id       BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    email    VARCHAR(255) NOT NULL UNIQUE,
    login    VARCHAR(255) NOT NULL UNIQUE,
    name     VARCHAR(255),
    birthday DATE         NOT NULL
);
```

**Films** — фильмы. Связана с `MPA_Ratings` через `rating_id`.

```sql
CREATE TABLE Films
(
    id          BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name        VARCHAR(255) NOT NULL,
    description TEXT         NOT NULL,
    releaseDate DATE,
    duration    BIGINT       NOT NULL,
    rating_id   BIGINT       NOT NULL REFERENCES MPA_Ratings (id)
);
```

### Связующие таблицы

**Friends** — заявки в друзья и подтверждённая дружба.

```sql
CREATE TABLE Friends
(
    user_id   BIGINT      NOT NULL REFERENCES Users (id),
    friend_id BIGINT      NOT NULL REFERENCES Users (id),
    status    VARCHAR(20) NOT NULL DEFAULT 'PENDING',
    PRIMARY KEY (user_id, friend_id)
);
```

**Film_Likes** — лайки пользователей.

```sql
CREATE TABLE Film_Likes
(
    film_id BIGINT NOT NULL REFERENCES Films (id),
    user_id BIGINT NOT NULL REFERENCES Users (id),
    PRIMARY KEY (user_id, film_id)
);
```

**Film_Genres** — связь фильмов с жанрами.

```sql
CREATE TABLE Film_Genres
(
    film_id  BIGINT NOT NULL REFERENCES Films (id),
    genre_id BIGINT NOT NULL REFERENCES Genres (id),
    PRIMARY KEY (film_id, genre_id)
);
```

## Примеры запросов

### Добавить лайк

```sql
INSERT INTO Film_Likes (film_id, user_id)
VALUES (1, 2)
ON CONFLICT (film_id, user_id) DO NOTHING;
```

### Удалить лайк

```sql
DELETE
FROM Film_Likes
WHERE film_id = 1
  AND user_id = 2;
```

### Топ-10 фильмов по количеству лайков

```sql
SELECT f.*, COUNT(fl.user_id) AS like_count
FROM Films f
         LEFT JOIN Film_Likes fl ON f.id = fl.film_id
GROUP BY f.id
ORDER BY like_count DESC LIMIT 10;
```

### Получить фильм по ID вместе с его жанрами

```sql
SELECT f.*, g.name AS genre_name
FROM Films f
         LEFT JOIN Film_Genres fg ON f.id = fg.film_id
         LEFT JOIN Genres g ON fg.genre_id = g.id
WHERE f.id = 1;
```

### Отправить заявку в друзья (или подтвердить существующую)

```sql
INSERT INTO Friends (user_id, friend_id, status)
VALUES (1, 2, 'PENDING') ON CONFLICT (user_id, friend_id) DO
UPDATE SET status = 'CONFIRMED';
```
